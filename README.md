# Incognita

Web estática de la smash burger de Envigado. Una sola hamburguesa, pedido por WhatsApp, lista para GitHub Pages.

## Qué incluye

- Smash burger de dos carnes: pan de papa, Brangus, queso americano, cebolla al gusto y salsa
- Precio: **$14.000** COP
- El envío no está incluido
- El botón de comprar abre WhatsApp al **322 680 0756** con el pedido armado
- Dirección: Envigado, Parque Principal

## Publicar en GitHub Pages

1. Sube este repositorio a GitHub.
2. En el repo: **Settings → Pages**.
3. Source: **Deploy from a branch**.
4. Branch: `main` (o `master`), folder: `/ (root)`.
5. Espera un minuto y abre `https://TU-USUARIO.github.io/TU-REPO/`.

No hay build. No hay `npm install`. La web son `index.html`, `styles.css` y `script.js`.

## Probar en local

```bash
python3 -m http.server 8080
```

Abre [http://localhost:8080](http://localhost:8080).
